# Plot Agent Examples

This directory contains example agents demonstrating various features of the Plot Agent SDK.

## Examples

### [Hello World](./hello-world)

A minimal agent that creates a welcome activity when activated. Great for understanding the basics.

**Features:**

- Basic agent structure
- Activity creation
- Simple lifecycle hooks

## Running Examples

Each example can be run as a standalone agent:

1. Navigate to the example directory:

   ```bash
   cd examples/hello-world
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure your agent ID in `package.json`

4. Deploy:

   ```bash
   npm run deploy
   ```
