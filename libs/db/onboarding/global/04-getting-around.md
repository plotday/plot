## note: intro

Plot's goal is to get you to meaningful work as quickly as possible. Here are some tips for navigating efficiently.

## note: keyboard

**Keyboard Navigation**

- **⌘N** (Ctrl+N on Windows, ⌘⌃N / Ctrl+Alt+N on web browsers): Create a new note
- **⌘/** (Ctrl+/ on Windows): Search across all your threads and focuses
- **⌘K** (Ctrl+K on Windows): Open the command palette
- **⌘J** (Ctrl+J on Windows, ⌘⌃J / Ctrl+Alt+J on web browsers): Switch to another focus
- **⌘D** (Ctrl+D on Windows): To do / Done — toggle whether this thread requires action
- **⌘⇧D** (Ctrl+Shift+D on Windows): Schedule a thread to do later
- **⌘Up/Down** (Ctrl+Up/Down on Windows): Open previous/next thread
- **⌘Enter** (Ctrl+Enter on Windows): When adding a note, mark it (and the thread) to do

## note: touch

**Touch Gestures**

- **Long press** on items to drag and reorder
- **Swipe right** on threads: To do
- **Swipe right (long)** on threads: Schedule to do later
- **Swipe left** on threads: Done
- **Swipe left (long)** on items to open a menu with all commands
