# Imap Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `Imap` built-in tool to the Twister SDK and API worker that provides high-level IMAP operations (connect, list mailboxes, select, search, fetch, set flags, disconnect) for building email connectors like Apple Mail.

**Architecture:** New `Imap` tool follows the same pattern as `Network` — SDK types in `public/twister/src/tools/imap.ts`, implementation in `workers/api/src/twist/tools/imap.ts`, wired through the factory. The implementation uses Cloudflare Workers' `connect()` TCP API for TLS sockets and handles IMAP protocol parsing and MIME decoding internally. Sessions are in-memory maps scoped to a single execution.

**Tech Stack:** TypeScript, Cloudflare Workers TCP sockets (`connect()`), IMAP protocol (RFC 3501), MIME parsing

**Spec:** `docs/superpowers/specs/2026-03-31-imap-tool-design.md`

### Task 3: API Worker — IMAP Protocol Layer

This is the core implementation. The IMAP protocol layer handles TCP connections, command/response parsing, and session management.

**Files:**
- Create: `workers/api/src/twist/tools/imap.ts`

- [ ] **Step 1: Write the Imap tool implementation**

Create `workers/api/src/twist/tools/imap.ts`. The implementation:

- Extends `Tool` (RpcTarget) and implements the SDK's `Imap` interface (`IImap`)
- Uses Cloudflare Workers `connect()` API for TCP/TLS sockets
- Manages sessions via `Map<string, ImapConnection>` keyed by `crypto.randomUUID()`
- Each `ImapConnection` holds: socket, writer (`WritableStreamDefaultWriter<Uint8Array>`), reader (`ReadableStreamDefaultReader<Uint8Array>`), tagCounter (number), buffer (string), selectedMailbox (string | null)
- Validates the requested host against `this.hosts` before connecting
- IMAP commands use tagged commands (`A0001 LOGIN ...`, `A0002 SELECT ...`)
- Responses are parsed line-by-line, splitting untagged (`*`) from tagged (`A0001 OK`)

Key internal methods:

- `sendCommand(conn, command)` — sends tagged command, collects untagged responses until tagged response arrives, returns `{ ok, text, untagged }`
- `readLine(conn)` — reads from reader into buffer, extracts lines at `\r\n`
- `quoteString(s)` — IMAP quoted string escaping
- `parseListResponse(line)` — parses `* LIST (\flags) "delimiter" "name"` into `ImapMailbox`
- `parseSelectResponse(mailbox, untagged)` — extracts EXISTS, RECENT, UIDVALIDITY, UIDNEXT, UNSEEN
- `buildSearchArgs(criteria)` — converts `ImapSearchCriteria` to IMAP SEARCH arguments
- `parseFetchResponses(untagged, ...)` — extracts UID, FLAGS, ENVELOPE, body from FETCH responses
- `extractTextFromMime(body, contentType)` — basic MIME boundary splitting and part extraction
- `decodeTransferEncoding(headers, content)` — handles base64 and quoted-printable
- `decodeImapString(s)` — handles RFC 2047 encoded words (`=?charset?B?...?=`)

Public methods map directly to the SDK interface:

| Method | IMAP Command |
|--------|-------------|
| `connect(options)` | TCP connect + `LOGIN` |
| `listMailboxes(session)` | `LIST "" "*"` |
| `selectMailbox(session, mailbox)` | `SELECT "mailbox"` |
| `search(session, criteria)` | `UID SEARCH ...criteria` |
| `fetchMessages(session, uids, options)` | `UID FETCH uid1,uid2 (UID FLAGS ENVELOPE RFC822.SIZE BODY.PEEK[TEXT] BODYSTRUCTURE)` |
| `setFlags(session, uids, flags, op)` | `UID STORE uid1,uid2 +FLAGS/-FLAGS/FLAGS (flags)` |
| `disconnect(session)` | `LOGOUT` + socket close |

Static method:
```typescript
static Permissions(options?: ImapOptions): ToolPermission[] {
  const hosts = options?.hosts || [];
  return hosts.map((host) => ({
    domain: "imap",
    entity: host,
    flags: ["use"] as const,
  }));
}

import { describe, expect, it } from "vitest";

import { Imap } from "../imap";

describe("Imap", () => {
  describe("Permissions", () => {
    it("should return permissions for declared hosts", () => {
      const permissions = Imap.Permissions({
        hosts: ["imap.mail.me.com"],
      });

      expect(permissions).toEqual([
        {
          domain: "imap",
          entity: "imap.mail.me.com",
          flags: ["use"],
        },
      ]);
    });

    it("should return permissions for multiple hosts", () => {
      const permissions = Imap.Permissions({
        hosts: ["imap.mail.me.com", "imap.gmail.com"],
      });

      expect(permissions).toHaveLength(2);
      expect(permissions[0]).toEqual({
        domain: "imap",
        entity: "imap.mail.me.com",
        flags: ["use"],
      });
      expect(permissions[1]).toEqual({
        domain: "imap",
        entity: "imap.gmail.com",
        flags: ["use"],
      });
    });

    it("should return empty array when no hosts provided", () => {
      const permissions = Imap.Permissions({});
      expect(permissions).toEqual([]);
    });

    it("should return empty array when options not provided", () => {
      const permissions = Imap.Permissions();
      expect(permissions).toEqual([]);
    });
  });

  describe("constructor", () => {
    it("should create instance without options", () => {
      const imap = new Imap();
      expect(imap).toBeDefined();
    });

    it("should create instance with host options", () => {
      const imap = new Imap({ hosts: ["imap.mail.me.com"] });
      expect(imap).toBeDefined();
    });
  });

  describe("connect", () => {
    it("should reject undeclared hosts", async () => {
      const imap = new Imap({ hosts: ["imap.mail.me.com"] });

      await expect(
        imap.connect({
          host: "imap.evil.com",
          port: 993,
          tls: true,
          username: "user",
          password: "pass",
        })
      ).rejects.toThrow(
        'IMAP host "imap.evil.com" is not in the declared hosts list'
      );
    });
  });
});
```
