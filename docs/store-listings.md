# App Store Listings

Ready-to-paste store copy for the Plot apps — Apple App Store (iOS and macOS),
Google Play (Android), and Microsoft Store (Windows). This is marketing source:
write everything here in Plot's voice (see [voice.md](./voice.md)) using the
current product terms from [features.md](./features.md).

## How to use this doc

- Each platform section holds every field that store asks for, with its
  character limit noted. Counts in parentheses are the length of the copy as
  written — re-check after any edit.
- The copy is tailored per store on purpose. Some repetition across stores is
  expected; don't try to share one description everywhere.
- **"What's New" / release notes** at the bottom is a reusable template — fill
  it per release. Never ship "Bug fixes and performance improvements."

## Rules baked into this copy (don't undo them)

- **Apple listings name no other platforms.** App Review rejects metadata that
  references Android, Windows, or other app marketplaces. The iOS and macOS copy
  below only ever mentions Apple devices (iPhone, iPad, Mac) and the web. Google
  Play and Microsoft Store copy may mention every platform, and does.
- **Third-party names live in the description, not the Apple keyword field.**
  Saying Plot "works with Gmail, Slack, and Linear" in the description is
  accurate and fine. Stuffing competitor trademarks into the 100-character
  keyword field invites a 2.3.7 rejection, so the keyword string stays generic.
- **Voice holds even under ASO pressure.** Title and subtitle lead with the real
  benefit in plain words, not a slogan. No hype words, no "boost your
  productivity," no "inbox zero." If a keyword can't earn its place in an honest
  sentence, it doesn't go in.

### Subtitle — 30 char max

```
Chat, email & app threads
```

(25) — Leads with "Chat" (not email), and deliberately does not repeat
"organized" from the name. Apple indexes the name and subtitle as separate
keyword fields, so this line spends its characters on fresh terms (chat, email,
app, threads) — the channels from the site tagline.

```
New: group your focuses under roles — Work, Personal, and more — so work and life stay on separate tracks, each with its own colors and notifications.
```

(150)

### Keywords — 100 char max, comma-separated, no spaces

```
tasks,inbox,calendar,to-do,todo,agenda,notes,reminders,meetings,productivity,focus,collaboration
```

(96) — Words already in the name (all, your, work, organized) and subtitle
(chat, email, app, threads) are omitted on purpose; Apple indexes those
separately. "tasks" is added here because it's no longer in the name or
subtitle, and it's a core search term for Plot. Integration names (Slack, Gmail,
Linear, Notion) are kept out of this field to avoid a trademark rejection — they
appear in the description instead.

## Release notes ("What's New") — reusable template

Specific and human. Name what changed and why it helps. Never "Bug fixes and
performance improvements." Group several items as short lines. Keep platform
mentions out of the Apple version.

**Template**

```
What's new in this version:

• <Plain-language description of the change and what it does for you>
• <Another change>

Fixes and small improvements:
• <Specific fix a user would notice>
```

**Filled example (works for any store)**

```
What's new in this version:

• Roles: group your focuses under Work, Personal, and more — each with its own colors and notifications, so work and life stay on separate tracks.
• A new FYI focus gathers low-signal mail — newsletters, receipts, promotions — in one muted place to skim on your own schedule, and keeps it out of your Inbox.

Fixes and small improvements:
• Opening a thread no longer bumps it to the top of your Done list.
• Faster focus switching and a calmer agenda when you move between focuses.
```
