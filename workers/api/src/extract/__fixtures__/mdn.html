Array.prototype.map()

The map() method of Array instances creates a new array populated with the results of calling a provided function on every element in the calling array.

Try it

const array1 = [1, 4, 9, 16];

// Pass a function to map
const map1 = array1.map((x) => x * 2);

console.log(map1);
// Expected output: Array [2, 8, 18, 32]

Syntax

map(callbackFn)
map(callbackFn, thisArg)

Parameters

callbackFn

A function to execute for each element in the array. Its return value is added as a single element in the new array. The function is called with the following arguments:

Return value

A new array with each element being the result of the callback function.

Description

The map() method is an iterative method. It calls a provided callbackFn function once for each element in an array and constructs a new array from the results.

callbackFn is invoked only for array elements which have assigned values. It is not invoked for empty slots in sparse arrays.

A more involved example

const numbers = [1, 4, 9];
const doubles = numbers.map((num) => num * 2);

// doubles is now [2, 8, 18]
// numbers is still [1, 4, 9]

This shows the basic mechanic of map. It does not mutate the original array.

When working with arrays of objects, the callback receives each object and can return a transformed version, which is collected into the new array. This pattern is widely used in functional code.

If you only need iteration without producing a new array, prefer forEach() or a for...of loop. map() is wasteful when its return value is unused.
